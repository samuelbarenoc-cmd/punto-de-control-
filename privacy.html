Política de privacidad

Última actualización: 18 de noviembre de 2026

1. Quiénes somos

"Punto de Control" es una aplicación personal que automatiza la subida de vídeos al canal de YouTube del mismo nombre. Es utilizada exclusivamente por el propietario del canal.

2. Qué datos usa la aplicación

La aplicación solicita el permiso youtube.upload de la API de YouTube, que solo sirve para subir vídeos al canal del propietario que lo autoriza. Para funcionar guarda, únicamente en el ordenador del propietario, un token de acceso que permite repetir esas subidas.

3. Qué no hacemos

  • No recopilamos datos personales de visitantes ni de terceros.
  • No vendemos, compartimos ni transferimos datos a terceros.
  • No leemos ni descargamos vídeos, comentarios ni datos de otras cuentas.
  • No usamos los datos para publicidad.

4. Conservación y eliminación

El token se almacena solo de forma local. El propietario puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions y borrar el archivo local del token.

5. Servicios de Google

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado. Los vídeos se publican en YouTube, que se rige por las Políticas de privacidad de Google.

6. Contacto

Para cualquier consulta sobre esta política, escribe al correo de contacto indicado en el canal de YouTube Punto de Control.
